Google スプレッドシート自動転送設定 (GAS)

Google Apps Script (GAS) WebhookのURLを設定すると、本アプリで仕訳を登録するたびにリアルタイムでGoogleスプレッドシートにデータが保存されます。

導入手順（5分で完了）

  1. Googleスプレッドシートを新規作成します。
  2. メニューの **「拡張機能」 > 「Apps Script」** を開きます。
  3. 表示されたコードエディタに、下記のスクリプトをすべてコピー＆ペーストします。
  4. 右上 **「デプロイ」 > 「新しいデプロイ」** をクリック。
  5. 種類を **「ウェブアプリ」** に選択し、アクセスできるユーザーを **「全員 (Anyone)」** に変更してデプロイします。
  6. 発行された **「ウェブアプリ URL」** をコピーして、上記の入力欄に貼り付けて保存してください。
Google Apps Script (Code.gs) 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["ID", "日付", "借方科目", "金額", "貸方科目", "摘要"]);
  }
  
  sheet.appendRow([
    data.id,
    data.date,
    data.debit,
    data.amount,
    data.credit,
    data.desc
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
